# Animal API

A simple API built with FastAPI and MongoDB for managing animal records. The API supports operations to create, filter, update, delete and read animals including image uploads. 

# Features

- **CRUD Operations:** Create, read, update, and delete animal records.
- **Image Upload:** Attach images to animal records.
- **Filtering:** Filter animals by name, species, and age.
- **Interactive Documentation:** Auto-generated Swagger UI available at `/docs`.

# Prerequisites

- Python 3.7 or higher
- MongoDB running locally (default URI: `mongodb://localhost:27017/`)
