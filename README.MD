# Microblog

Microblog is a web application built using Flask that allows users to create accounts, log in, post messages, follow other users, and reset passwords. It provides a simple and intuitive interface for users to share their thoughts and stay connected with others.

## Features

- **User Authentication**: Users can create accounts and log in securely.
- **Posting Messages**: Users can write and share their thoughts through posts.
- **Following Users**: Users can follow other users to see their posts in a personalized feed.
- **Password Reset**: Users can reset their passwords if they forget them.

## Technologies Used

- **Flask**: A lightweight WSGI web application framework in Python.
- **SQLite**: A C-language library that provides a lightweight, disk-based database.
- **Bootstrap**: A front-end framework for developing responsive and mobile-first websites.
